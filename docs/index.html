Shop geofence

Pan/zoom anywhere in Canada, then click the map (or drag the red dot) to place the shop. Drag the white handle to resize. The boxes below fill in as you move.
Phones pick up the new zone the next time the app starts. Clock-out radius must be larger than clock-in. Wi-Fi is a second presence signal for indoors, where GPS is unreliable — a phone on the shop network counts as on site even if GPS says otherwise. It must match the network name exactly. To find it: stand in the shop, open the app, and read the "This phone is on:" line on the Setup screen. Leave blank to run on GPS alone. Only set from here — crew phones deliberately cannot change it.
